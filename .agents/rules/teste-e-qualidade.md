9. TESTES E QUALIDADE

RULE 043 — Testes unitários

Toda funcionalidade relevante deve possuir testes unitários.

RULE 044 — Testes de integração

Teste interações entre:

Django e banco de dados.

Django e motor científico.

Frontend e API.

Supabase Auth e backend.

Storage e aplicação.

RULE 045 — Testes matemáticos

Utilize resultados conhecidos, propriedades matemáticas e invariantes para verificar algoritmos.

RULE 046 — Cobertura

A cobertura deve ser acompanhada, mas não deve substituir a qualidade dos testes.

Priorize código crítico, regras de negócio e cálculos científicos.

RULE 047 — Ferramentas

Utilize:

Pytest.

Pytest-Cov.

Ruff.

Mypy.

TypeScript.

Ferramentas de teste do frontend conforme a stack adotada.
